Course admin

Toggle admissions open/closed, edit course details, or add a new course. Changes save directly to data/courses.json in your GitHub repository, so the live site updates as soon as the commit is made (usually within a minute on GitHub Pages).

This page writes to your repository using a GitHub personal access token that you paste below. The token is kept only in this browser tab's memory (sessionStorage) — it is never sent anywhere except GitHub's API, and it disappears when you close the tab. Do not use this page on a shared or public computer, and use a fine-grained token scoped only to this one repository. See README.md → "Using the admin panel" for how to create one.
